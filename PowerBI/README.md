# Power BI Dashboard

This folder contains the Power BI dashboard developed for the HR Analytics – Employee Attrition project.

The dashboard provides interactive analysis of:

- Total Employees
- Employees Left
- Attrition Rate
- Average Age
- Average Monthly Income
- Department Performance
- Job Role Performance
- Gender Distribution
- Overtime vs Attrition
- Job Satisfaction
- Age Distribution
- Income by Job Role
- Work-Life Balance
- Education Field

### Dashboard Filters

- Department
- Job Role
- Education Field
- Gender
