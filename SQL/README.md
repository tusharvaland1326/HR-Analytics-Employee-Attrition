# SQL Analysis

This folder contains the SQL scripts used for the HR Analytics – Employee Attrition project.

The SQL analysis covers employee attrition, department performance, job-role analysis, salary, overtime, employee demographics, and other HR business insights.

### SQL Topics

- Employee and attrition analysis
- Department analysis
- Job-role analysis
- Gender analysis
- Age analysis
- Salary analysis
- Overtime analysis
- Job satisfaction analysis
- Work-life balance analysis
- Employee segmentation
- Attrition-rate calculations
- Business-focused HR analysis
