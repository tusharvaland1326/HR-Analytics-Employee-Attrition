# Reports

This folder contains the professional reports created for the HR Analytics – Employee Attrition project.

The report documents:

- Project Overview
- Business Objectives
- Dataset Description
- Data Analysis Methodology
- Key Performance Indicators
- Key Findings
- Employee Attrition Analysis
- Department Analysis
- Job Role Analysis
- Salary and Compensation Analysis
- Overtime Analysis
- Job Satisfaction
- Work-Life Balance
- Power BI Dashboard
- SQL Analysis
- Business Recommendations
- Skills Demonstrated
- Project Learning Outcomes
- Analytical Interpretation
- Conclusion
- Author Information
